# Hiba Saaydeh Portfolio

A bilingual, static portfolio for Hiba Al-Sayda. The website is plain HTML, CSS, and JavaScript; it has no Node.js runtime, build step, backend, or package dependencies.

## Run locally

Open `site/index.html` in a browser. The site assets and downloadable work are stored alongside it in `site/assets/` and `site/files/`.

## Deployment

GitHub Actions publishes the contents of `site/` directly to GitHub Pages. No build command or server is required.

- Live site: [Heba Al-Sayda](https://heba-al-sayda.github.io/portfolio/)
- Every push to `main` and manual workflow dispatch deploy the static files.
- In the repository's **Settings → Pages**, set the source to **GitHub Actions**.
